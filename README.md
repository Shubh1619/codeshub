# codeshub

Software. Websites. Apps. SaaS. Built for Growth.

Codeshub is a development agency site built with Next.js, React, and Tailwind CSS. It includes the marketing pages (home, services, products, portfolio, careers, contact) with a dark-by-default theme system, an enquiry form, and a careers board.

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm start` — serve the production build

## Tech

- Next.js (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
